## 四、最有想法的几个

**`fishcg/dsh-airpod-control`** — 用 AirPods 头部动作回答权限提示：点头允许、摇头拒绝。需要 macOS + 带头部追踪的 AirPods。把空间交互接进 agent 审批流。

**`agent-body` 里的 `dsh-cortex`** — 记忆做成"器官"：静默 2 分钟进浅睡，5 分钟进深睡，睡眠期间整理记忆。

**`akslcw/dsh-negative-ledger`** — 记录**失败**：命令失败、文件不存在的路径连同前置条件一起记进证据账本，下次遇到就警告或阻止。

**`BW741/dsh-video-eyes`** — 让模型真看视频：本地 ffmpeg 抽带时间戳的帧 + faster-whisper 转录音轨，逐帧读真实像素。

**`dsh-inpage-translator`** — 每个页面挂常驻翻译按钮，点一下就地替换可见文本，再点还原。

**`263311487-ux/dsh-verify`** — 浏览器验收：输入 JSON spec，用真 Chromium 判定通过或退回。

## 八、判断

生态一万多个插件，**真正在用的不到一百个**。官方正在逐步内置功能，有的文件编辑器插件就是因为官方加了工作区文件树而主动停更。

装之前先问：它补的是不是官方还没做的缺口？否则过两个月就被内置功能替代了。

### 建议先试的

1. `@liustack/modlens` — 你经常发截图问问题，这个能省不少来回
2. `yoursc/dsh-siyuan` — 接上你写文章那套流水线
3. `dsh-backup` / `dsh-config-manager` — 开发者预览期破坏性变更是常态，备份迟早需要
